
CLI Project Management Tool

A structured, command-line interface (CLI) project management system designed for development teams. This tool allows administrators to seamlessly manage users, projects, and tasks while establishing relational data mapping and leveraging an external service for advanced project capabilities.

Features


User Management

• Create Users: Register new developers into the system with role-based attributes.
• List Users: Display all registered team members in a structured format.

Project Tracking

• Add Projects: Create and assign new projects directly to specific users.
• Display Associations: View projects mapped via a one-to-many relationship (one user can manage multiple projects).

Task & Contributor Management

• Assign Tasks: Add granular tasks directly to existing projects.
• Complete Tasks: Track progress by marking tasks as completed through the CLI.
• Multi-Developer Mapping: Manage complex many-to-many relationships where projects connect to tasks and feature multiple assigned contributors.

AI & External Service Integration

• External Package Feature: Integrates a third-party package or API service to enhance core utility.
• AI Project Client: Features a reusable external service/AI client designed to support and power an advanced project-management automation command.

Data Persistence & Interface

• File I/O: Structural data is fully persisted across sessions using robust local file I/O operations.
• Intuitive CLI: Navigate the entire ecosystem utilizing clear, interactive, and user-friendly console commands.
